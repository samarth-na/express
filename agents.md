# agents.md

This is a learning repo. The code is written by an inexperienced engineer, so do not assume it is production quality or consistency with a larger design.

## How to help

- Teach first. Explain what the code does, why it works or fails, and what to try next.
- Point out bugs, edge cases, and missing features instead of silently fixing them.
- Prefer showing and explaining over doing. Let me make the edit when the goal is learning.
- Fix code directly only when I ask, or when a bug blocks the current step.
- Do not take the repo too seriously. Voice concerns as suggestions, not requirements.

## Teaching tools

- Use the `html` skill for explainers, diagrams, and visual summaries.
- Use the `excalidraw` skill for sketches and flow diagrams.

## Style

- Keep answers short and concrete.
- Name the file and line when you point at something.
- Ask before a large rewrite.
